# 1 dp核心在于问题分解+分类讨论+DFS/递推+时空优化

> 递归搜索+保存计算结果=**记忆化搜索**
> 	1. 自顶向下算=记忆化搜索
> 	2. 自底向上算=递推
> 	3. dfs 或者 dp 是指前 xxx 个元素的和，而不是第 xxx 个元素的值

> **dp 技巧-dp 五步**
> `1.状态定义`：求解结果依赖的是前 i 次选择，还是第 i 次选择，自变量是 i 和限制变量，选择后的结果即所求目标是因变量，一般而言限制变量和因变量都是状态，都需要更新；
> `2.做选择`：状态变化的依据，**0-1 选择做 or 不做 or 求和，多个选择遍历选最值 or 求和**；
> `3.状态初始化`：dfs 的叶子节点边界条件和返回值，递推的 dp 初始化，状态转移是 max 时不合法值用 `Integer.MIN_VALUE/2`，min 时用 `Integer.MIN_VALUE/2`(*避免整形溢出*)，sum 时用 `0`，恰好，至多，至少等在初始化时有所不同；
> `4.状态转移`：*f(i+1,t)=f(i,t)+f(i,T) or f(i+1,t)=max(f(i,t),f(i,T)) or min(f(i,t)+f(i,T))*，根据选择不同确定**分段函数**，dfs 回溯解法自顶向下，递推解法外部循环遍历目标数组，内层遍历选择，自底向上；如果当前状态依赖前一个状态（i-1）则升序，如果依赖后一个状态（i+1）则降序；
> `5.memo备忘录+滚动更新`：memo 用于 dfs 记录历史记录实现剪枝优化时间复杂度，**初始化为非有效值以作区分**，滚动更新用几个临时变量保存前置依赖状态优化空间复杂度，**初始化为有效值以作种子**

**dp分类**
1. 树形dp：进行dfs递归左子树和右子树构建`深度、高度、直径、路径长度`(*从根节点开始，遍历每一个节点认为是分叉节点计算其最大路径长度，更新总长度和当前节点的最大长度*)等
2. 树形dp（最大独立集问题）：最大独立集需要从图中选择尽量多的点，使得这些点互不相邻。变形：最大化点权之和；树形打家劫舍，dfs递归的结果不一定是一个状态，可以是一组状态，保存多个状态以适配顶层的多种选择。

# 2 回溯三问与 DP

![image.png|450](http://img.fcs.cloudns.ch/pics/20260318153310683.png)

- **第一问：当前操作？（决策）**
    - **含义：** 面对第 ii 个物品，我有哪些选择？
    - **图片解读：** 只有两种选择——**选** 或者 **不选**。这是二叉树的分支逻辑。
    - **作用：** 确定了搜索树的分支结构。
- **第二问：子问题？（状态定义）**
    - **含义：** 我现在的函数 f(i,c)f(i,c) 到底代表什么意思？
    - **图片解读：** “在剩余容量为 cc 时，从前 ii 个物品中得到的最大价值和”。
    - **作用：** 这是最关键的一步。它定义了递归函数的参数（ii 和 cc）以及返回值（最大价值）。一旦定义清楚，代码的骨架就有了。
- **第三问：下一个子问题？（状态转移/递归）**
    - **含义：** 如果我做了第一问的选择，问题会变成什么样？
    - **图片解读：**
        - **不选：** 问题变成了“从前 i−1i−1 个物品里选，容量还是 cc”。即 f(i−1,c)f(i−1,c)。
        - **选：** 问题变成了“从前 i−1i−1 个物品里选，容量变成了 c−w[i]c−w[i]”。即 f(i−1,c−w[i])f(i−1,c−w[i])。
    - **作用：** 这直接导出了状态转移方程（递归公式）： f(i,c)=max⁡(f(i−1,c),f(i−1,c−w[i])+v[i])f(i,c)=max(f(i−1,c),f(i−1,c−w[i])+v[i]) _(注：图片中第三问虽然没写 +v[i]+v[i]，但在计算“最大价值”时，选物品必然要加上该物品的价值)_

```java
# 对应第二问：定义函数含义
# i: 当前考虑到第几个物品
# c: 当前剩余容量
# 返回值：最大价值
def dfs(i, c):
    # 边界条件（图片没写，但实际代码需要）
    if i < 0: 
        return 0
    
    # 对应第一问 & 第三问：分类讨论
    
    # 情况1：不选第 i 个物品
    # 对应图片：不选 -> 剩余容量 c 不变 -> 下一个子问题是前 i-1 个物品
    res_not_pick = dfs(i - 1, c)
    
    # 情况2：选第 i 个物品 (前提是容量够)
    res_pick = -float('inf')
    if c >= w[i]:
        # 对应图片：选 -> 剩余容量 c - w[i] -> 下一个子问题是前 i-1 个物品
        # 注意：这里要加上当前物品的价值 v[i]
        res_pick = dfs(i - 1, c - w[i]) + v[i]
        
    # 取最大值
    return max(res_not_pick, res_pick)
```

# 3 动态规划解题技巧完全指南

## 3.1 一、核心概念：什么是动态规划？

### 3.1.1 直观理解

```
动态规划 = 记忆化搜索 + 递推

核心思想：把大问题拆成小问题，存储小问题的解，避免重复计算

类比：
┌─────────────────────────────────────────────────────────┐
│  爬楼梯：要到第10层，必须从第9层或第8层上来            │
│                                                         │
│  普通递归：f(10) = f(9) + f(8)                         │
│           f(9) = f(8) + f(7)  ← f(8)重复计算了！       │
│                                                         │
│  动态规划：f(1)=1, f(2)=2                              │
│           f(3)=f(2)+f(1)=3    ← 算一次，存起来         │
│           f(4)=f(3)+f(2)=5    ← 直接用存的值           │
│           ... 依次计算到 f(10)                         │
└─────────────────────────────────────────────────────────┘
```

### 3.1.2 适用条件

```
┌─────────────────────────────────────────────────────────┐
│  最优子结构                                              │
│  ├── 大问题的最优解包含小问题的最优解                    │
│  └── 例：最短路径问题                                   │
│                                                         │
│  重叠子问题                                              │
│  ├── 同一个小问题会被多次计算                           │
│  └── 例：斐波那契数列 f(n)=f(n-1)+f(n-2)               │
│                                                         │
│  无后效性                                                │
│  ├── 当前的状态一旦确定，之后的演变就不受之前状态影响   │
│  └── 例：当前位置(i,j)，不需要知道怎么来的，只知道在哪  │
└─────────────────────────────────────────────────────────┘
```

## 3.2 二、解题五步法

```
┌─────────────────────────────────────────────────────────┐
│  Step 1: 定义状态(当前状态) dp[i] 或 dp[i][j] 的含义      │
│  Step 2: 找出状态转移方程 （每个状态如何计算）             │
│  Step 3: 确定初始条件和边界(初始状态的值)                  │
│  Step 4: 确定计算顺序（自底向上 / 自顶向下）               │
│  Step 5: 优化空间复杂度（数组标记，双指针标记）             │
└─────────────────────────────────────────────────────────┘
```

## 3.3 三、五大经典问题类型

### 3.3.1 线性 DP - 一维状态

**例题：爬楼梯（LeetCode 70）**

```
问题：每次爬1或2个台阶，爬到第n层有多少种方法？
```

```java
class Solution {
    public int climbStairs(int n) {
        // Step 1: 定义状态
        // dp[i] = 爬到第i层的方法数
      
        if (n <= 2) return n;
      
        // Step 3: 初始条件
        int[] dp = new int[n + 1];
        dp[1] = 1;  // 第1层：1种方法
        dp[2] = 2;  // 第2层：2种方法（1+1 或 2）
      
        // Step 4: 计算顺序（从前往后）
        for (int i = 3; i <= n; i++) {
            // Step 2: 状态转移
            // 到第i层，只能从第i-1层（爬1步）或第i-2层（爬2步）
            dp[i] = dp[i - 1] + dp[i - 2];
        }
      
        return dp[n];
      
        // Step 5: 空间优化
        // int a = 1, b = 2;
        // for (int i = 3; i <= n; i++) {
        //     int c = a + b;
        //     a = b;
        //     b = c;
        // }
        // return b;
    }
}
```

**状态转移图解：**

```
台阶:    0    1    2    3    4    5
方法:    1    1    2    3    5    8
         ↓    ↓   ↗↗   ↗↗   ↗↗   ↗↗
              └──┘   └──┘   └──┘ 
              dp[i] = dp[i-1] + dp[i-2]
```

### 3.3.2 二维 DP - 矩阵路径问题

**例题：最小路径和（LeetCode 64）**

```
问题：从矩阵左上角走到右下角，每次只能右移或下移，求最小路径和

输入:
[ [1,3,1],
  [1,5,1],
  [4,2,1] ]
输出: 7 (1→3→1→1→1)
```

```java
class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
      
        // Step 1: 定义状态
        // dp[i][j] = 从(0,0)到的最小路径和
      
        int[][] dp = new int[m][n];
      
        // Step 3: 初始条件
        dp[0][0] = grid[0][0];
      
        // 第一行：只能从左边来
        for (int j = 1; j < n; j++) {
            dp[0][j] = dp[0][j - 1] + grid[0][j];
        }
      
        // 第一列：只能从上边来
        for (int i = 1; i < m; i++) {
            dp[i][0] = dp[i - 1][0] + grid[i][0];
        }
      
        // Step 4: 计算顺序（从上到下，从左到右）
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                // Step 2: 状态转移
                // 到只能从上边来或从左边来
                dp[i][j] = Math.min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j];
            }
        }
      
        return dp[m - 1][n - 1];
    }
}
```

**图解过程：**

```
原矩阵:              DP矩阵:
┌───┬───┬───┐        ┌───┬───┬───┐
│ 1 │ 3 │ 1 │        │ 1 │ 4 │ 5 │  第一行累加
├───┼───┼───┤   →    ├───┼───┼───┤
│ 1 │ 5 │ 1 │        │ 2 │ 7 │ 6 │  dp[i][j] = min(上,左) + 当前
├───┼───┼───┤        ├───┼───┼───┤
│ 4 │ 2 │ 1 │        │ 6 │ 8 │ 7 │  最终答案: dp[2][2] = 7
└───┴───┴───┘        └───┴───┴───┘
```

### 3.3.3 子序列问题

> `nums的LIS（最长递增自序列）等价于nums与排序去重后的nums的LCS（最长公共子序列）`

**例题：最长递增子序列（LeetCode 300）**

```
问题：找出最长严格递增子序列的长度

输入: [10,9,2,5,3,7,101,18]
输出: 4 (子序列 [2,3,7,101])
```

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        if (n == 0) return 0;
      
        // Step 1: 定义状态
        // dp[i] = 以nums[i]结尾的最长递增子序列长度
      
        int[] dp = new int[n];
        Arrays.fill(dp, 1);  // 每个元素自己就是一个长度为1的子序列
      
        int maxLen = 1;
      
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                // Step 2: 状态转移
                // 如果nums[i] > nums[j]，可以把nums[i]接在dp[j]后面
                if (nums[i] > nums[j]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
            maxLen = Math.max(maxLen, dp[i]);
        }
      
        return maxLen;
    }
}
```

**图解过程：**

```
nums:  [10, 9, 2, 5, 3, 7, 101, 18]

i=0: dp[0]=1  [10]
i=1: dp[1]=1  [9] (没有比9小的元素在前面)
i=2: dp[2]=1  [2]
i=3: dp[3]=2  [2,5] (5>2, 接在dp[2]后面)
i=4: dp[4]=2  [2,3] (3>2, 接在dp[2]后面)
i=5: dp[5]=3  [2,3,7] 或 [2,5,7]
i=6: dp[6]=4  [2,3,7,101] 或 [2,5,7,101]
i=7: dp[7]=4  [2,3,7,18] 或 [2,5,7,18]

答案: max(dp) = 4
```

### 3.3.4 背包问题

#### 3.3.4.1 0-1 背包

##### 3.3.4.1.1 变体

![image.png](http://img.fcs.cloudns.ch/pics/20260318004304969.png)

```
问题：n个物品，每个物品有重量w[i]和价值v[i]，背包容量W
     每个物品只能选或不选，求最大价值
```

```java
public int knapsack(int W, int[] wt, int[] val) {
    int n = wt.length;
  
    // dp[i][w] = 前i个物品，容量为w时的最大价值
    int[][] dp = new int[n + 1][W + 1];
  
    for (int i = 1; i <= n; i++) {
        for (int w = 1; w <= W; w++) {
            // 不选第i个物品
            dp[i][w] = dp[i - 1][w];
          
            // 选第i个物品（如果能装下）
            if (w >= wt[i - 1]) {
                dp[i][w] = Math.max(dp[i][w], 
                                    dp[i - 1][w - wt[i - 1]] + val[i - 1]);
            }
        }
    }
  
    return dp[n][W];
}

// 空间优化：一维数组
public int knapsackOpt(int W, int[] wt, int[] val) {
    int n = wt.length;
    int[] dp = new int[W + 1];
  
    for (int i = 0; i < n; i++) {
        // 注意：从后往前遍历，避免重复使用
        for (int w = W; w >= wt[i]; w--) {
            dp[w] = Math.max(dp[w], dp[w - wt[i]] + val[i]);
        }
    }
  
    return dp[W];
}
```

**图解过程：**

```
物品: 重量[2,3,4,5], 价值[3,4,5,6], 背包容量W=8

二维DP表:
        容量w:  0   1   2   3   4   5   6   7   8
物品i=0(无)    [0,  0,  0,  0,  0,  0,  0,  0,  0]
i=1(重量2价值3)[0,  0,  3,  3,  3,  3,  3,  3,  3]
i=2(重量3价值4)[0,  0,  3,  4,  4,  7,  7,  7,  7]
i=3(重量4价值5)[0,  0,  3,  4,  5,  7,  8,  9,  9]
i=4(重量5价值6)[0,  0,  3,  4,  5,  7,  8,  9, 10]

答案: dp[4][8] = 10 (选物品1和4，重量2+5=7，价值3+6=9，还剩空间)
           实际选物品2和3，重量3+4=7，价值4+5=9
           选物品1、2、3，重量2+3+4=9>8，不行
           最优：物品1、2、4，重量2+3+5=10>8，不行
           最优解是物品1、3或物品2、3，价值9
```

#### 3.3.4.2 完全背包

```
问题：每种物品可以选择无限次
```

```java
public int completeKnapsack(int W, int[] wt, int[] val) {
    int n = wt.length;
    int[] dp = new int[W + 1];
  
    for (int i = 0; i < n; i++) {
        // 注意：从前往后遍历，允许重复使用
        for (int w = wt[i]; w <= W; w++) {
            dp[w] = Math.max(dp[w], dp[w - wt[i]] + val[i]);
        }
    }
  
    return dp[W];
}
```

**0-1 背包 vs 完全背包：**

```
┌────────────────┬─────────────────┬─────────────────┐
│                │    0-1背包      │    完全背包      │
├────────────────┼─────────────────┼─────────────────┤
│ 物品使用次数    │   最多1次       │   无限次         │
├────────────────┼─────────────────┼─────────────────┤
│ 遍历顺序       │   从后往前      │   从前往后       │
├────────────────┼─────────────────┼─────────────────┤
│ 原因          │ 避免重复使用    │ 允许重复使用     │
└────────────────┴─────────────────┴─────────────────┘
```

### 3.3.5 编辑距离问题

**例题：编辑距离（LeetCode 72）**

```
问题：将word1转换成word2的最少操作次数
     操作：插入、删除、替换
```

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length(), n = word2.length();
      
        // dp[i][j] = word1前i个字符转换成word2前j个字符的最少操作数
        int[][] dp = new int[m + 1][n + 1];
      
        // 初始化：word1变成空串需要删除i次
        for (int i = 1; i <= m; i++) dp[i][0] = i;
        // 空串变成word2需要插入j次
        for (int j = 1; j <= n; j++) dp[0][j] = j;
      
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    // 字符相同，不需要操作
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    dp[i][j] = Math.min(
                        dp[i - 1][j - 1],  // 替换
                        Math.min(
                            dp[i - 1][j],   // 删除word1[i-1]
                            dp[i][j - 1]    // 插入word2[j-1]
                        )
                    ) + 1;
                }
            }
        }
      
        return dp[m][n];
    }
}
```

**图解过程：**

## 3.4 四、状态转移方程推导技巧

### 3.4.1 找"最后一步"

```
思考方向：问题的最后一步是什么？

例：跳跃游戏
     最后一步是从某个位置跳到终点
     那个位置能跳到终点吗？再往前推...

例：最长递增子序列
     最后一步是选择某个元素作为序列的最后一个
     在它之前有多少个比它小的元素？
```

### 3.4.2 找"选择"

```
思考方向：每一步有哪些选择？

例：背包问题
     每个物品：选 或 不选
     dp[i][w] = max(不选, 选)

例：不同路径
     每一步：向右 或 向下
     dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

### 3.4.3 找"状态"

```
思考方向：用什么变量能完整描述当前情况？

例：股票问题
     状态：天数、持有状态
     dp[i][0] = 第i天不持有股票的最大利润
     dp[i][1] = 第i天持有股票的最大利润

例：打家劫舍
     状态：当前房子、是否偷
     dp[i][0] = 第i家不偷的最大金额
     dp[i][1] = 第i家偷的最大金额
```

## 3.5 五、代码模板速查

### 3.5.1 一维 DP 模板

```java
// 基础版
int[] dp = new int[n];
dp[0] = 初始值;
for (int i = 1; i < n; i++) {
    dp[i] = 状态转移方程;
}
return dp[n-1];

// 空间优化版
int a = 初始值, b = 初始值;
for (int i = 2; i < n; i++) {
    int c = 状态转移方程;
    a = b;
    b = c;
}
return b;
```

### 3.5.2 二维 DP 模板

```java
int[][] dp = new int[m][n];

// 初始化第一行和第一列
for (int j = 0; j < n; j++) dp[0][j] = 初始值;
for (int i = 0; i < m; i++) dp[i][0] = 初始值;

// 状态转移
for (int i = 1; i < m; i++) {
    for (int j = 1; j < n; j++) {
        dp[i][j] = 状态转移方程;
    }
}
return dp[m-1][n-1];
```

### 3.5.3 背包 DP 模板

```java
// 0-1背包
int[] dp = new int[W + 1];
for (int i = 0; i < n; i++) {
    for (int w = W; w >= wt[i]; w--) {  // 从后往前
        dp[w] = Math.max(dp[w], dp[w - wt[i]] + val[i]);
    }
}

// 完全背包
int[] dp = new int[W + 1];
for (int i = 0; i < n; i++) {
    for (int w = wt[i]; w <= W; w++) {  // 从前往后
        dp[w] = Math.max(dp[w], dp[w - wt[i]] + val[i]);
    }
}
```

## 3.7 七、优化技巧

### 3.7.1 空间优化

```java
// 二维 → 一维
int[][] dp = new int[m][n];
// 优化：
int[] dp = new int[n];  // 只保留一行

// 一维 → 变量
int[] dp = new int[n];
// 优化：
int a, b, c;  // 只保留几个变量
```

### 3.7.2 剪枝优化

```java
// 提前终止
for (int i = 0; i < n; i++) {
    if (满足条件) break;  // 提前退出
    // ...
}

// 跳过无效计算
for (int i = 0; i < n; i++) {
    if (无效条件) continue;  // 跳过
    // ...
}
```

## 3.9 九、总结

```
动态规划解题心法：

1. 找状态：用什么变量描述当前局面？
2. 找转移：当前状态由哪些状态转移而来？
3. 找边界：最小的子问题是什么？
4. 找顺序：按什么顺序计算保证依赖已求解？

记住：大问题 = 小问题 + 决策
      状态定义清楚了，转移方程就清晰了
```

> 0-1 背包内层循环从后往前，不可重复选
> 完全背包内层循环从前往后，可重复选
> dp 时间复杂度：`状态个数 * 单个状态的计算时间`

等于目标值：终止条件 target=0 且返回 0，内层循环边界 x
至多目标值：初始化为 1，终止条件返回 1，内层循环边界 x
至少目标值：终止条件 target<=0 且返回 0，内层循环边界 0
