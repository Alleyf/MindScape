## 0.2 回溯三问：思考回溯问题的套路

站在回溯树的一个节点上，你只需要思考 3 个问题：
![image.png|500](http://img.fcs.cloudns.ch/pics/20260314172019602.png)
**行为级：**
- 当前操作？（当前操作的区间，不能被子问题重复包含）
- 枚举子问题？（只能选择剩余的子空间继续切割，从小到大，从局部到整体）
- 下一个子问题？
**约束级：**
- 路径：也就是已经做出的选择。
- 选择列表：也就是你当前可以做的选择。
- 结束条件：也就是到达决策树底层，无法再做选择的条件。

**两种思路**
- 输入的视角：是否选择选项
- 答案的视角：选项集合中必选一个选项

> 时间复杂度是`O（n\*C(2n,n)）`

### 0.2.1 回溯算法解决排列组合子集问题的模板

**核心差异对比**

```txt
┌─────────────┬──────────────────┬──────────────────┬──────────────────┐
│   问题类型   │     全排列        │      组合        │      子集        │
├─────────────┼──────────────────┼──────────────────┼──────────────────┤
│   选择范围   │   每次都从0开始   │   从start开始    │   从start开始    │
│             │   (跳过已用的)    │                  │                  │
├─────────────┼──────────────────┼──────────────────┼──────────────────┤
│   避免重复   │   used[] 数组    │   start 参数     │   start 参数     │
├─────────────┼──────────────────┼──────────────────┼──────────────────┤
│   收集时机   │   到达叶子节点    │   到达叶子节点    │   每个节点都收集  │
├─────────────┼──────────────────┼──────────────────┼──────────────────┤
│   终止条件   │   path.size()==n │   path.size()==k │   无（自然结束）  │
└─────────────┴──────────────────┴──────────────────┴──────────────────┘
```

```java
#从答案角度每次都必须从答案集合中选一个，不能不选
void backtrack(路径, 选择列表) {
    if (满足结束条件) {
        result.add(路径);
        return;
    }
    
    for (选择 : 选择列表) {
        做选择;           // path.append(x)
        backtrack(路径);   // 递归
        撤销选择;         // path.deleteCharAt() ← 这一步很关键！
    }
}

#从是否选择角度，每次可选可不选
void backtrack(路径, 选择列表) {
    if (满足结束条件) {
        result.add(路径);
        return;
    }
    
    不做选择
    backtrack(路径);   // 递归
    
    做选择;           // path.append(x)
    backtrack(路径);   // 递归
    撤销选择;         // path.deleteCharAt() ← 这一步很关键！
}


# 组合/子集模板
void backtrack(int[] nums, int start) {
    if (是子集问题) 收集结果;  // 子集：每个节点都收集
    
    if (终止条件) {
        收集结果;              // 组合：叶子节点收集
        return;
    }
    
    if (需要剪枝) return;
    if (需要去重) return;
    
    for (int i = start; i < nums.length; i++) {  // 从start开始

        
        做选择;
        backtrack(nums, i + 1);  // 注意是 i + 1
        撤销选择;
    }
}

# 排列模板
void backtrack(int[] nums，boolean[] used) {
    if (终止条件) {
        收集结果;
        return;
    }
    
    if (used[i]) continue;               // 跳过已用
    if (需要去重) continue;                // 去重逻辑
    
    for (int i = 0; i < nums.length; i++) {  // 每次从头遍历
        做选择;
        used[i] = true;
        backtrack(nums);
        used[i] = false;
        撤销选择;
    }
}
```

> **回溯算法的精髓就是"做选择 → 递归 → 撤销选择+剪枝"！**

### 0.2.3 组合型回溯

LC77.组合
LC216.组合总和 III
ILC22.括号生成

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> combine(int n, int k) {
        List<List<Integer>> res = new ArrayList<>();
        List<Integer> path = new ArrayList<>();
        dfs(n, k, n, res, path);
        return res;
    }
    
    /**
     * @param n 总数范围 [1,n]
     * @param k 需要选择的个数
     * @param start 当前可以选择的最大数字
     * @param res 存放结果
     * @param path 当前路径
     */
    private void dfs(int n, int k, int start, 
                     List<List<Integer>> res, List<Integer> path) {
        
        // 1️⃣ 终止条件
        if (path.size() == k) {
            res.add(new ArrayList<>(path));
            return;
        }
        
        // 2️⃣ 剪枝：剩余数字不够选了
        if (start < k - path.size()) {
            return;
        }
        
        // 3️⃣ 从大到小枚举（避免重复组合）
        for (int i = start; i >= k - path.size(); i--) {
            path.add(i);                    // ✅ 做选择
            dfs(n, k, i - 1, res, path);    // ✅ 递归
            path.remove(path.size() - 1);   // ✅ 回溯
        }
    }
}
```

> **循环用 i，递归传 i-1，先终止后剪枝，不传全局变**
