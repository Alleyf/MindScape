### 0.1.1 🥇 第一梯队（必会核心）

#### 0.1.1.1 📌 LeetCode 20. 有效的括号

- 🔍 **核心考点**：栈匹配、哈希映射
- 💡 **解题思路**：遍历字符串，左括号入栈；右括号检查栈顶是否匹配，匹配则弹出。遍历结束栈必须为空。
- 🛠️ **算法方法**：栈 + 配对映射
- ⏱️ **复杂度**：时间 `O(n)` / 空间 `O(n)`
- 💻 **考场 Java 代码**：

```java
class Solution {
    public boolean isValid(String s) {
        if (s == null || s.length() == 0) return true;
        Deque<Character> stack = new ArrayDeque<>();
        Map<Character, Character> map = new HashMap<>();
        map.put(')', '('); map.put(']', '['); map.put('}', '{');
        
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '[' || c == '{') {
                stack.push(c);
            } else {
                if (stack.isEmpty() || stack.pop() != map.get(c)) return false;
            }
        }
        return stack.isEmpty();
    }
}
```

- ⚠️ **手写避坑/技巧**：空串直接 `true`；最后必须判 `stack.isEmpty()`；面试可直接写 `switch` 代替 `Map` 降依赖。

### 0.1.2 🥈 第二梯队（高频重点）

#### 0.1.2.1 📌 LeetCode 200. 岛屿数量

- 🔍 **核心考点**：网格遍历、BFS/DFS、沉岛思想
- 💡 **解题思路**：遍历网格，遇 `'1'` 计数+1 并启动搜索，将连通的所有 `'1'` 标记为 `'0'`（避免重复计数）。
- 🛠️ **算法方法**：多起点 BFS（迭代防栈溢出）
- ⏱️ **复杂度**：时间 `O(mn)` / 空间 `O(min(m,n))`
- 💻 **考场 Java 代码**：

```java
class Solution {
    public int numIslands(char[][] grid) {
        if (grid == null || grid.length == 0) return 0;
        int m = grid.length, n = grid[0].length, count = 0;
        int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
        
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == '1') {
                    count++;
                    bfs(grid, i, j, m, n, dirs);
                }
            }
        }
        return count;
    }
    private void bfs(char[][] grid, int i, int j, int m, int n, int[][] dirs) {
        Deque<int[]> q = new ArrayDeque<>();
        q.offer(new int[]{i, j});
        grid[i][j] = '0'; // 入队即标记
        while (!q.isEmpty()) {
            int[] cur = q.poll();
            for (int[] d : dirs) {
                int x = cur[0] + d[0], y = cur[1] + d[1];
                if (x >= 0 && x < m && y >= 0 && y < n && grid[x][y] == '1') {
                    grid[x][y] = '0';
                    q.offer(new int[]{x, y});
                }
            }
        }
    }
}
```

- ⚠️ **手写避坑/技巧**：**入队立刻标记**，否则同一节点重复入队爆内存；华子偏好迭代 BFS。

#### 0.1.2.2 📌 LeetCode 1. 两数之和

- 🔍 **核心考点**：哈希表一次遍历
- 💡 **解题思路**：边遍历边记录 `target - nums[i]` 的索引。若当前数已在表中，说明找到配对。
- 🛠️ **算法方法**：HashMap 空间换时间
- ⏱️ **复杂度**：时间 `O(n)` / 空间 `O(n)`
- 💻 **考场 Java 代码**：

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int need = target - nums[i];
            if (map.containsKey(need)) return new int[]{map.get(need), i};
            map.put(nums[i], i);
        }
        return new int[]{}; // 题目保证有解
    }
}
```

- ⚠️ **手写避坑/技巧**：先查后存，避免同一元素被复用两次；返回值是**索引**不是值。

#### 0.1.2.3 📌 LeetCode 3. 无重复字符的最长子串

- 🔍 **核心考点**：滑动窗口、字符位置映射
- 💡 **解题思路**：右指针扩展窗口，遇重复字符时左指针直接跳到该字符上次出现位置的下一位。
- 🛠️ **算法方法**：滑动窗口 + `int[128]` 记录最后索引
- ⏱️ **复杂度**：时间 `O(n)` / 空间 `O(Σ)` (ASCII=128)
- 💻 **考场 Java 代码**：

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int[] last = new int[128];
        Arrays.fill(last, -1);
        int max = 0, left = 0;
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            if (last[c] >= left) left = last[c] + 1; // 窗口收缩
            last[c] = right;
            max = Math.max(max, right - left + 1);
        }
        return max;
    }
}
```

- ⚠️ **手写避坑/技巧**：用 `int[128]` 替代 `HashMap` 更快且无 API 负担；`left` 只能向右跳，不能回退。

### 0.1.3 🥉 第三梯队（常考进阶）

#### 0.1.3.1 📌 LeetCode 46. 全排列

- 🔍 **核心考点**：回溯算法、状态恢复
- 💡 **解题思路**：DFS 枚举所有位置，用 `used` 数组标记已选元素，递归到底记录路径，返回时撤销选择。
- 🛠️ **算法方法**：回溯（选/撤销）
- ⏱️ **复杂度**：时间 `O(n·n!)` / 空间 `O(n)`
- 💻 **考场 Java 代码**：

```java
class Solution {
    public List<List<Integer>> permute(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        backtrack(nums, new boolean[nums.length], new ArrayList<>(), res);
        return res;
    }
    private void backtrack(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
        if (path.size() == nums.length) {
            res.add(new ArrayList<>(path)); // 必须新建副本
            return;
        }
        for (int i = 0; i < nums.length; i++) {
            if (used[i]) continue;
            used[i] = true;
            path.add(nums[i]);
            backtrack(nums, used, path, res);
            path.remove(path.size() - 1); // 撤销
            used[i] = false;
        }
    }
}
```

- ⚠️ **手写避坑/技巧**：`res.add(new ArrayList<>(path))` 易错；若有重复元素需排序+剪枝（LC 47）。

#### 0.1.3.2 📌 LeetCode 994. 腐烂的橘子

- 🔍 **核心考点**：多源 BFS、层序遍历
- 💡 **解题思路**：初始所有烂橘子入队，按分钟分层扩散。记录扩散轮数，结束后检查是否还有新鲜橘子。
- 🛠️ **算法方法**：多源 BFS
- ⏱️ **复杂度**：时间 `O(mn)` / 空间 `O(mn)`
- 💻 **考场 Java 代码**：

```java
class Solution {
    public int orangesRotting(int[][] grid) {
        int m = grid.length, n = grid[0].length, fresh = 0;
        Deque<int[]> q = new ArrayDeque<>();
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) q.offer(new int[]{i, j});
                else if (grid[i][j] == 1) fresh++;
            }
        }
        if (fresh == 0) return 0;
        int[][] dirs = {{1,0},{-1,0},{0,1},{0,-1}};
        int minutes = 0;
        while (!q.isEmpty()) {
            minutes++;
            for (int k = q.size(); k > 0; k--) { // 按层遍历
                int[] cur = q.poll();
                for (int[] d : dirs) {
                    int x = cur[0]+d[0], y = cur[1]+d[1];
                    if (x>=0 && x<m && y>=0 && y<n && grid[x][y]==1) {
                        grid[x][y] = 2; fresh--;
                        q.offer(new int[]{x, y});
                    }
                }
            }
        }
        return fresh == 0 ? minutes - 1 : -1; // 多算了一层
    }
}
```

- ⚠️ **手写避坑/技巧**：初始无新鲜橘子直接返回 `0`；循环结束后 `minutes-1`（最后一次弹出无新感染）。

#### 0.1.3.3 📌 LeetCode 394. 字符串解码

- 🔍 **核心考点**：栈处理嵌套结构
- 💡 **解题思路**：双栈分别存数字倍数和临时字符串。遇 `[` 入栈重置，遇 `]` 出栈重复拼接，遇字母追加。
- 🛠️ **算法方法**：双栈迭代
- ⏱️ **复杂度**：时间 `O(n)` / 空间 `O(n)`
- 💻 **考场 Java 代码**：

```java
class Solution {
    public String decodeString(String s) {
        Deque<Integer> numStk = new ArrayDeque<>();
        Deque<StringBuilder> strStk = new ArrayDeque<>();
        StringBuilder cur = new StringBuilder();
        int num = 0;
        for (char c : s.toCharArray()) {
            if (Character.isDigit(c)) num = num * 10 + (c - '0');
            else if (c == '[') {
                numStk.push(num); strStk.push(cur);
                cur = new StringBuilder(); num = 0;
            } else if (c == ']') {
                StringBuilder tmp = cur;
                cur = strStk.pop();
                int count = numStk.pop();
                for (int i = 0; i < count; i++) cur.append(tmp);
            } else cur.append(c);
        }
        return cur.toString();
    }
}
```

- ⚠️ **手写避坑/技巧**：注意多位数字解析 `num*10`；结果可能很长，问清是否需取模。

#### 0.1.3.4 📌 LeetCode 739. 每日温度

- 🔍 **核心考点**：单调递减栈
- 💡 **解题思路**：栈存索引，保持温度递减。当前温度高于栈顶时，说明栈顶找到了更高温度，计算天数差并弹出。
- 🛠️ **算法方法**：单调栈
- ⏱️ **复杂度**：时间 `O(n)` / 空间 `O(n)`
- 💻 **考场 Java 代码**：

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] res = new int[n];
        Deque<Integer> stk = new ArrayDeque<>(); // 存索引
        for (int i = 0; i < n; i++) {
            while (!stk.isEmpty() && temperatures[i] > temperatures[stk.peek()]) {
                int idx = stk.pop();
                res[idx] = i - idx;
            }
            stk.push(i);
        }
        return res;
    }
}
```

- ⚠️ **手写避坑/技巧**：结果数组初始为 `0` 符合题意；栈内只存索引，比较用 `temperatures[idx]`。

#### 0.1.3.5 📌 LeetCode 56. 合并区间

- 🔍 **核心考点**：排序 + 贪心合并
- 💡 **解题思路**：按起点排序。遍历区间，若当前起点 ≤ 结果集末区间终点，则合并（更新终点为最大值）；否则新增。
- 🛠️ **算法方法**：排序 + 线性扫描
- ⏱️ **复杂度**：时间 `O(n log n)` / 空间 `O(log n)`
- 💻 **考场 Java 代码**：

```java
class Solution {
    public int[][] merge(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
        List<int[]> res = new ArrayList<>();
        for (int[] cur : intervals) {
            if (res.isEmpty() || cur[0] > res.get(res.size()-1)[1]) {
                res.add(cur);
            } else {
                res.get(res.size()-1)[1] = Math.max(res.get(res.size()-1)[1], cur[1]);
            }
        }
        return res.toArray(new int[res.size()][]);
    }
}
```

- ⚠️ **手写避坑/技巧**：**必须先排序**；合并时只更新右端点；单区间直接返回。

#### 0.1.3.6 📌 LeetCode 64. 最小路径和

- 🔍 **核心考点**：网格 DP、空间优化
- 💡 **解题思路**：`dp[i][j] = grid[i][j] + min(上, 左)`。首行首列单独初始化，可原地修改省空间。
- 🛠️ **算法方法**：二维 DP（原地优化）
- ⏱️ **复杂度**：时间 `O(mn)` / 空间 `O(1)`
- 💻 **考场 Java 代码**：

```java
class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        for (int j = 1; j < n; j++) grid[0][j] += grid[0][j-1];
        for (int i = 1; i < m; i++) grid[i][0] += grid[i-1][0];
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                grid[i][j] += Math.min(grid[i-1][j], grid[i][j-1]);
            }
        }
        return grid[m-1][n-1];
    }
}
```

- ⚠️ **手写避坑/技巧**：问清是否允许修改原数组；不允许则用 `dp[n]` 滚动数组。

#### 0.1.4.1 📌 LeetCode 155. 最小栈

- 🔍 **核心考点**：辅助栈同步
- 💡 **解题思路**：主栈存数据，辅助栈同步存当前最小值。`push` 时辅助栈压入 `min(val, peek())`。
- 🛠️ **算法方法**：双栈
- ⏱️ **复杂度**：时间 `O(1)` / 空间 `O(n)`
- 💻 **考场 Java 代码**：

```java
class MinStack {
    private Deque<Integer> stk, minStk;
    public MinStack() { stk = new ArrayDeque<>(); minStk = new ArrayDeque<>(); minStk.push(Integer.MAX_VALUE); }
    public void push(int val) { stk.push(val); minStk.push(Math.min(val, minStk.peek())); }
    public void pop() { stk.pop(); minStk.pop(); }
    public int top() { return stk.peek(); }
    public int getMin() { return minStk.peek(); }
}
```

#### 0.1.4.2 📌 LeetCode 986. 区间列表的交集

- 🔍 **核心考点**：双指针、区间数学
- 💡 **解题思路**：交集为 `[max(s1,s2), min(e1,e2)]`。若 `start<=end` 有效，移动终点较小的指针。
- 🛠️ **算法方法**：双指针扫描
- ⏱️ **复杂度**：时间 `O(m+n)` / 空间 `O(1)`
- 💻 **考场 Java 代码**：

```java
class Solution {
    public int[][] intervalIntersection(int[][] A, int[][] B) {
        List<int[]> res = new ArrayList<>();
        int i = 0, j = 0;
        while (i < A.length && j < B.length) {
            int start = Math.max(A[i][0], B[j][0]);
            int end = Math.min(A[i][1], B[j][1]);
            if (start <= end) res.add(new int[]{start, end});
            if (A[i][1] < B[j][1]) i++; else j++;
        }
        return res.toArray(new int[res.size()][]);
    }
}
```

#### 0.1.4.3 📌 LeetCode 456. 132模式（⚠️非132题）

- 🔍 **核心考点**：单调栈、逆向遍历
- 💡 **解题思路**：从右向左找 `3`（单调递减栈），弹出时更新 `2`。若遇 `<2` 的数，说明找到 `1`，返回 `true`。
- 🛠️ **算法方法**：单调栈逆序
- ⏱️ **复杂度**：时间 `O(n)` / 空间 `O(n)`
- 💻 **考场 Java 代码**：

```java
class Solution {
    public boolean find132pattern(int[] nums) {
        int third = Integer.MIN_VALUE;
        Deque<Integer> stk = new ArrayDeque<>();
        for (int i = nums.length - 1; i >= 0; i--) {
            if (nums[i] < third) return true;
            while (!stk.isEmpty() && nums[i] > stk.peek()) third = stk.pop();
            stk.push(nums[i]);
        }
        return false;
    }
}
```

#### 0.1.4.4 📌 LeetCode 11. 盛最多水的容器

- 🔍 **核心考点**：对撞双指针、贪心
- 💡 **解题思路**：双指针从两端向中间。面积由短板决定，每次移动较短边以寻找更高板。
- 🛠️ **算法方法**：双指针收缩

- 💻 **考场 Java 代码**：

```java
class Solution {
    public int maxArea(int[] height) {
        int l = 0, r = height.length - 1, max = 0;
        while (l < r) {
            int h = Math.min(height[l], height[r]);
            max = Math.max(max, h * (r - l));
            if (height[l] < height[r]) l++; else r--;
        }
        return max;
    }
}
```

#### 0.1.4.5 📌 LeetCode 49. 字母异位词分组

- 🔍 **核心考点**：哈希分组、频次统计
- 💡 **解题思路**：用 `int[26]` 统计字符频次，拼接成 `String` 作 Key，相同 Key 归为一组。
- 🛠️ **算法方法**：HashMap + 计数数组 Key
- ⏱️ **复杂度**：时间 `O(n·k)` / 空间 `O(n·k)`

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            int[] cnt = new int[26];
            for (char c : s.toCharArray()) cnt[c - 'a']++;
            StringBuilder key = new StringBuilder();
            for (int v : cnt) key.append(v).append('#');
            map.computeIfAbsent(key.toString(), k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(map.values());
    }
}
```

#### 0.1.4.6 📌 LeetCode 71. 简化路径

- 🔍 **核心考点**：栈处理路径字符串
- 💡 **解题思路**：按 `/` 分割，忽略空串和 `.`，遇 `..` 弹栈，其他入栈。最后逆序拼接。
- 🛠️ **算法方法**：栈 + 字符串分割
- ⏱️ **复杂度**：时间 `O(n)` / 空间 `O(n)`
- 💻 **考场 Java 代码**：

```java
class Solution {
    public String simplifyPath(String path) {
        Deque<String> stk = new ArrayDeque<>();
        for (String p : path.split("/")) {
            if (p.isEmpty() || p.equals(".")) continue;
            if (p.equals("..")) { if (!stk.isEmpty()) stk.pop(); }
            else stk.push(p);
        }
        if (stk.isEmpty()) return "/";
        StringBuilder sb = new StringBuilder();
        while (!stk.isEmpty()) sb.insert(0, "/" + stk.pop());
        return sb.toString();
    }
}
```

#### 0.1.4.8 📌 LeetCode 1423. 可获得的最大点数

- 🔍 **核心考点**：滑动窗口转化、逆向思维
- 💡 **解题思路**：取两端 k 张 = 剩下中间 `n-k` 张和最小。用定长滑动窗口求最小子数组和，总和减去即可。
- 🛠️ **算法方法**：滑动窗口求最小连续子数组
- ⏱️ **复杂度**：时间 `O(n)` / 空间 `O(1)`
- 💻 **考场 Java 代码**：

```java
class Solution {
    public int maxScore(int[] cardPoints, int k) {
        int n = cardPoints.length, total = 0;
        for (int p : cardPoints) total += p;
        int win = n - k, cur = 0, min = Integer.MAX_VALUE;
        if (win == 0) return total;
        for (int i = 0; i < n; i++) {
            cur += cardPoints[i];
            if (i >= win) cur -= cardPoints[i - win];
            if (i >= win - 1) min = Math.min(min, cur);
        }
        return total - min;
    }
}
```
