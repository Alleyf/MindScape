## 0.1 应用场景

> 找**第一个**比它大/小的元素

- 上一个更大（小）元素
- 下一个更大（小）元素

**在 $O(N)$ 时间内，寻找数组中每个元素左边或右边第一个比它大/小的元素。**

### 0.2.1 一、核心识别标志（看到这些词想单调栈）

如果在题目描述中出现以下关键词，优先考虑单调栈：

### 0.2.2 二、两大万能模板（背下来）

单调栈的核心在于**维护栈内元素的单调性**。通常建议**存下标（index）**而不是存值，方便计算距离。

#### 0.2.2.1 寻找“下一个更大元素” (维护单调递减栈)

*   **场景**：找右边第一个比当前大的数。
*   **逻辑**：栈底到栈顶递减。遇到比栈顶大的数，栈顶元素出栈（因为它找到了“下一个更大”）。

```python
def nextGreaterElement(nums):
    n = len(nums)
    res = [-1] * n  # 默认结果为 -1
    stack = []      # 存下标
    
    for i in range(n):
        # 当当前元素 > 栈顶元素对应的值时，栈顶元素找到了“下一个更大”
        while stack and nums[i] > nums[stack[-1]]:
            idx = stack.pop()
            res[idx] = nums[i]  # 或者记录距离 i - idx
        stack.append(i)
    return res
```

#### 0.2.2.2 寻找“下一个更小元素” (维护单调递增栈)

*   **场景**：找右边第一个比当前小的数。
*   **逻辑**：栈底到栈顶递增。遇到比栈顶小的数，栈顶元素出栈。

```python
def nextSmallerElement(nums):
    n = len(nums)
    res = [-1] * n
    stack = []
    
    for i in range(n):
        # 当当前元素 < 栈顶元素对应的值时
        while stack and nums[i] < nums[stack[-1]]:
            idx = stack.pop()
            res[idx] = nums[i]
        stack.append(i)
    return res
```

### 0.2.3 三、高频变体与解题技巧

#### 0.2.3.1 循环数组 (Circular Array)

*   **题目特征**：数组首尾相连（如 LeetCode 503）。
*   **技巧**：将数组复制一份拼接到后面（`nums + nums`），遍历长度变为 `2n`，取模获取索引 `i % n`。
*   **注意**：结果数组长度仍为 `n`。

#### 0.2.3.2 柱状图最大矩形 (LeetCode 84)

*   **核心难点**：确定矩形的**宽度**。
*   **技巧**：
    *   使用**单调递增栈**。
    *   当元素 `nums[i]` 导致栈顶 `top` 出栈时：
        *   `top` 的高度是 `nums[top]`。
        *   `top` 的右边界是 `i` (第一个比它小的)。
        *   `top` 的左边界是 `stack[-1]` (栈里新的栈顶，即左边第一个比它小的)。
        *   **宽度** = `i - stack[-1] - 1`。
    *   **哨兵技巧**：在数组首尾各加一个 `0`，避免处理栈空和剩余元素的边界判断。

#### 0.2.3.3 接雨水 (LeetCode 42)

*   **技巧**：单调递减栈。
*   **逻辑**：栈里存的是左边的墙。遇到比栈顶高的墙（右墙），就可以计算中间凹槽的水量。
*   **水量公式**：`宽度 * (min(左墙高，右墙高) - 底高)`。

#### 0.2.3.4 寻找“左边”第一个大/小

*   **技巧**：
    *   方法 A：从右向左遍历数组（逻辑同“下一个”）。
    *   方法 B：从左向右遍历，**在 `while` 循环之后，`stack[-1]` 就是左边第一个满足条件的元素**（如果栈不为空）。

### 0.2.4 四、备考避坑指南 (Debug Checklist)

1.  **存值还是存下标？**
    *   **强烈建议存下标**。因为计算距离、宽度、或者需要原数组值时，下标通用性更强。
2.  **栈空判断**
    *   在访问 `stack[-1]` 之前，务必检查 `while stack:`。
    *   计算宽度时，如果栈空了，说明左边没有更小的，左边界视为 `-1`。
3.  **相等元素处理**
    *   如果是严格单调（`>` 或 `<`），相等元素会留在栈里。
    *   如果是非严格单调（`>=` 或 `<=`），相等元素会被弹出。
    *   **考试策略**：通常使用严格单调（`>` 或 `<`），除非题目特殊要求。
4.  **剩余元素**
    *   遍历结束后，栈里剩下的元素意味着右边没有满足条件的数。根据题目要求，结果通常设为 `-1` 或 `0`。
5.  **哨兵法 (Sentinel)**
    *   对于直方图问题，在数组头部插入 `0` 可以简化“栈空”的判断逻辑。

---

### 0.2.5 五、记忆口诀 (Mental Model)

> **大压小，找更小；小压大，找更大。**
> **出栈时刻定边界，宽度就是下标差。**

*   **大压小**：维护单调递减栈（大的在底下），遇到小的就压入，遇到大的就弹出。弹出时说明找到了**下一个更大**。
*   **小压大**：维护单调递增栈（小的在底下），遇到大的就压入，遇到小的就弹出。弹出时说明找到了**下一个更小**。

## 0.3 框架说明

> 及时 `去掉无用数据`，保证栈中数据 `有序`。

1. **结构**：栈内元素保持单调递增或递减
2. **目的**：快速找到每个元素的下一个更大/更小元素
3. **操作**：遍历数组，比较当前元素与栈顶，若破坏单调性则弹出栈顶并记录结果
4. **时间复杂度**：O(n)，每个元素最多入栈出栈一次
5. **典型应用**：
   - 下一个更大元素（NGE）
   - 下一个更小元素（NLE）
   - 柱状图最大矩形
   - 接雨水问题

**实现框架**：

```python
def monotonic_stack(arr, is_increasing=True):
    stack = []  # 存储索引
    result = [0] * len(arr)
    for i, val in enumerate(arr):
        while stack and (arr[stack[-1]] < val if is_increasing else arr[stack[-1]] > val):
            idx = stack.pop()
            result[idx] = i - idx  # 或存储具体值
        stack.append(i)
    return result
```

**关键点**：栈中存储索引而非值，便于计算距离或获取原始值。

### 0.3.1 Java 框架

```java
import java.util.Stack;

public class MonotonicStack {
    
    // 下一个更大元素（NGE）- 返回距离
    public static int[] nextGreaterElement(int[] arr) {
        int n = arr.length;
        int[] result = new int[n];
        Stack<Integer> stack = new Stack<>(); // 存储索引
        
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && arr[stack.peek()] < arr[i]) {
                int idx = stack.pop();
                result[idx] = i - idx; // 距离
            }
            stack.push(i);
        }
        
        // 处理栈中剩余元素（没有更大元素）
        while (!stack.isEmpty()) {
            result[stack.pop()] = 0;
        }
        return result;
    }
    
    // 下一个更小元素（NLE）- 返回距离
    public static int[] nextSmallerElement(int[] arr) {
        int n = arr.length;
        int[] result = new int[n];
        Stack<Integer> stack = new Stack<>();
        
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && arr[stack.peek()] > arr[i]) {
                int idx = stack.pop();
                result[idx] = i - idx;
            }
            stack.push(i);
        }
        
        while (!stack.isEmpty()) {
            result[stack.pop()] = 0;
        }
        return result;
    }
    
    // 通用框架（可自定义比较逻辑）
    public static int[] monotonicStack(int[] arr, boolean increasing) {
        int n = arr.length;
        int[] result = new int[n];
        Stack<Integer> stack = new Stack<>();
        
        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && 
                   (increasing ? arr[stack.peek()] < arr[i] : arr[stack.peek()] > arr[i])) {
                int idx = stack.pop();
                result[idx] = i - idx;
            }
            stack.push(i);
        }
        
        while (!stack.isEmpty()) {
            result[stack.pop()] = 0;
        }
        return result;
    }
    
    // 示例用法
    public static void main(String[] args) {
        int[] heights = {2, 1, 5, 6, 2, 3};
        System.out.println("NGE: " + java.util.Arrays.toString(nextGreaterElement(heights)));
        System.out.println("NLE: " + java.util.Arrays.toString(nextSmallerElement(heights)));
    }
}
```

**关键点**：
1. 使用 `Stack<Integer>` 存储索引
2. `while` 循环处理栈顶元素破坏单调性的情况
3. 先处理再入栈确保单调性
4. 最后处理栈中剩余元素（无结果的情况）

**变体扩展**：
- 返回具体值而非距离：`result[idx] = arr[i]`
- 处理环形数组：遍历 `2n` 次，用 `i % n` 取模
- 柱状图最大矩形：结合高度和宽度计算
