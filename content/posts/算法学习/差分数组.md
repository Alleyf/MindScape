## 0.1 应用场景

**差分数组的主要适用场景是频繁对原始数组的某个区间的元素进行增减**。


## 0.2 框架模板

```java
// 差分数组工具类
class Difference {
    // 差分数组
    private int[] diff;
    
    // 输入一个初始数组，区间操作将在这个数组上进行
    public Difference(int[] nums) {
        diff = new int[nums.length];
        // 根据初始数组构造差分数组
        diff[0] = nums[0];
        for (int i = 1; i < nums.length; i++) {
            diff[i] = nums[i] - nums[i - 1];
        }
    }

    // 给闭区间 [i, j] 增加 val（可以是负数）
    public void increment(int i, int j, int val) {
        diff[i] += val;
        if (j + 1 < diff.length) {
            diff[j + 1] -= val;
        }
    }

    // 返回结果数组
    public int[] result() {
        int[] res = new int[diff.length];
        // 根据差分数组构造结果数组
        res[0] = diff[0];
        for (int i = 1; i < diff.length; i++) {
            res[i] = res[i - 1] + diff[i];
        }
        return res;
    }
}
```

## 0.3 算法步骤

1. 构建差分工具类Difference（注意范围区间的开闭，适当调整increment方法的区间）
2. 找出区间i，j的范围，定义结果数组和差分对象（长度为j-i+1）并初始化
3. 遍历输入的区间变化二维数组，获取区间端点和变化值，调用差分对象的increment方法处理
4. 返回处理后的差分对象的result方法的结果数组（根据结果做适配返回）
