## 0.1 应用场景

> 找**窗口内**的最大/最小元素

**在 $O(N)$ 时间内，寻找数组窗口中最大/最小的元素。**

## 0.2 备考精华

- 及时去掉无用数据保证双端队列有序
	1. 当前数字≥队尾，弹出队尾（和单调栈一样）
	2. 弹出队首不在窗口内的元素

单调队列（Monotonic Queue）是单调栈的“兄弟”，但在考试和面试中，它的**应用场景更具体**，主要是解决**滑动窗口最值问题**。如果说单调栈是找“下一个”，单调队列就是管“当前窗口”。

以下是为你整理的**单调队列备考精华技巧**，结构与单调栈篇保持一致，方便对比记忆。

---

### 0.2.1 一、核心识别标志（看到这些词想单调队列）

如果在题目描述中出现以下关键词，优先考虑单调队列：
1.  **“滑动窗口”** (Sliding Window)
2.  **“固定长度子数组”** (Fixed Size Subarray)
3.  **“区间最大值/最小值”** (Range Max/Min)
4.  **“限制距离/范围”** (如：`i - j <= k`)
5.  **DP 优化**：状态转移方程形如 $dp[i] = \max(dp[j]) + \dots$ 且 $j$ 在有限范围内。

---

### 0.2.2 二、核心逻辑与万能模板

单调队列通常使用 **双端队列 (Deque)** 实现。
**核心原则**：
1.  **队尾 (Back)**：维护单调性。新元素入队前，把队尾破坏单调性的元素弹出。
2.  **队头 (Front)**：维护窗口有效性。如果队头元素下标超出窗口范围，弹出。
3.  **结果**：队头元素即为当前窗口的最值。

#### 0.2.2.1 万能模板（以“滑动窗口最大值”为例）

*   **目标**：求长度为 `k` 的窗口内的最大值。
*   **维护**：单调**递减**队列（队头最大）。

```python
from collections import deque

def maxSlidingWindow(nums, k):
    if not nums: return []
    
    dq = deque()  # 存下标，方便判断是否出窗口
    res = []
    
    for i in range(len(nums)):
        # 1. 队头出队：如果队头下标已滑出窗口 (i - k)
        if dq and dq[0] == i - k:
            dq.popleft()
        
        # 2. 队尾维护单调性：当前值 > 队尾值，则队尾没用了（因为当前值更大且更晚过期）
        while dq and nums[i] > nums[dq[-1]]:
            dq.pop()
            
        # 3. 当前元素入队
        dq.append(i)
        
        # 4. 记录结果：只有当窗口形成后 (i >= k - 1) 才记录
        if i >= k - 1:
            res.append(nums[dq[0]])
            
    return res
```

### 0.2.3 三、单调栈 Vs 单调队列（考试必考区别）

| 特性       | 单调栈 (Monotonic Stack) | 单调队列 (Monotonic Queue)            |
| :------- | :-------------------- | :-------------------------------- |
| **数据结构** | 栈 (Stack) / 列表        | 双端队列 (Deque)                      |
| **操作端**  | 只在一端操作 (顶)            | 两端操作 (头尾)                         |
| **核心用途** | 找**第一个**比它大/小的元素      | 找**窗口内**的最大/最小元素                  |
| **弹出条件** | 遇到新元素破坏单调性时弹出         | 1. 破坏单调性 (尾)<br>2. **超出窗口范围 (头)** |
| **典型题**  | 接雨水、柱状图、每日温度          | 滑动窗口最大值、跳跃游戏                      |

### 0.2.4 四、高频变体与解题技巧

#### 0.2.4.1 滑动窗口最小值

*   **技巧**：将模板中的 `>` 改为 `<`，维护单调**递增**队列。
*   **结果**：队头即为最小值。

#### 0.2.4.2 变长窗口 (满足条件的最长/最短子数组)

*   **场景**：窗口大小不固定，但需满足 `max - min <= limit`。
*   **技巧**：使用**两个单调队列**（一个维护最大值，一个维护最小值）。
*   **逻辑**：右指针扩张，当 `max_q[0] - min_q[0] > limit` 时，左指针收缩，并更新两个队列的队头。

#### 0.2.4.3 单调队列优化 DP (进阶难点)

*   **场景**：$dp[i] = \max_{i-k \le j < i} \{ dp[j] \} + cost[i]$。
*   **技巧**：
    *   普通 DP 是 $O(N \cdot K)$。
    *   用单调队列维护 $dp[j]$ 的最值，将转移优化为 $O(1)$，总复杂度 $O(N)$。
    *   **关键点**：队列里存的是下标 $j$，比较的是 $dp[j]$ 的值。

#### 0.2.4.4 循环数组滑动窗口

*   **技巧**：同单调栈，将数组扩展为 `nums + nums[:k-1]`，遍历长度增加，下标取模或直接扩展。

### 0.2.5 五、备考避坑指南 (Debug Checklist)

1.  **存下标还是存值？**
    *   **必须存下标！** 因为判断元素是否“过期”（滑出窗口）需要知道它的索引位置。
2.  **何时记录答案？**
    *   容易错在 `i` 刚开始时就记录。必须满足 `i >= k - 1` 才表示第一个完整窗口形成。
3.  **队头移除时机**
    *   可以在入队前检查，也可以在入队后检查。
    *   **推荐**：在入队前检查 `dq[0] == i - k`，逻辑更清晰。
4.  **空队列判断**
    *   访问 `dq[0]` 或 `dq[-1]` 前，务必确保 `dq` 不为空。
5.  **库的使用**
    *   Python: `from collections import deque`
    *   C++: `#include <deque>`
    *   Java: `ArrayDeque` 或 `LinkedList` (推荐 ArrayDeque)
    *   **考试建议**：如果语言不支持双端队列，可以用数组模拟（头尾指针 `head`, `tail`）。

### 0.2.6 六、记忆口诀 (Mental Model)

> **队尾保单调，队头保窗口。**
> **新来大的踢旧小，旧的下标过期跑。**
> **只要队头不越界，当前最值它最好。**

*   **队尾保单调**：新元素进来，把队尾不如它的都踢走（因为新元素更大且活得更久）。
*   **队头保窗口**：检查队头是不是已经滑出窗口左边了。
*   **当前最值**：处理完上述两步，队头就是答案。

### 0.2.8 八、考试现场策略

1.  **判断题型**：看到“窗口”、“区间最值”、“距离限制”，直接画一个双端队列。
2.  **模拟过程**：在草稿纸上画一个数组和一个队列，模拟 `i=0, 1, 2` 时的入队、出队过程，确认队头是否代表最值。
3.  **数组模拟**：如果考试环境不允许用 `deque` 库（极少见），用数组 `q[N]` 和两个指针 `hh` (头), `tt` (尾) 模拟：
    *   入队：`q[++tt] = i`
    *   队尾弹出：`tt--`
    *   队头弹出：`hh++`
    *   取队头：`q[hh]`
4.  **时间复杂度**：如果暴力解法是 $O(N \cdot K)$，题目数据量 $N=10^5$，那必须用单调队列优化到 $O(N)$。
