# MindScape Project

## Overview

AI-Native 创意知识空间，基于 React + Vite + TypeScript 构建。

## Milestones

### v0.1 — Initial Release (2026-05-11)
- 首页、学习路线、资源库、笔记阅读、图谱、标签页
- 粒子背景、鼠标光晕、玻璃拟态
- AI 隐喻面板
- 笔记 TOC 滚动跟随
- 沉浸式阅读模式
- Markdown/PDF 导出
