# 多级下拉导航菜单 - 执行计划

## 任务概述
在顶部导航栏添加多级下拉菜单，包含：模型选型、工具推荐、AI Coding 实战指南三个子菜单，每个子菜单有独立页面。

## 技术上下文
- React + Vite + TypeScript，单文件SPA（App.tsx 包含所有页面组件）
- 路由: React Router v6
- 导航: `<nav className="fixed top-0 ...">` 在 App.tsx:2306
- 样式: Tailwind CSS + CSS变量，组件样式在 index.css
- 资源数据: `src/config/resources.ts` → `RESOURCE_CATEGORIES`

---

## 执行步骤

### Step 1: 创建导航下拉组件
**文件**: `src/components/NavDropdown.tsx`（新建）

**内容**:
- `NavDropdown` 组件：接收 `label` + `children`
- 使用 `useState` 控制展开/收起
- Hover 触发，鼠标离开收起
- 使用 `framer-motion` 的 `AnimatePresence` + `motion.div` 实现展开动画
- 样式：绝对定位dropdown面板，玻璃态背景

**预期结果**: 可复用的下拉菜单组件
